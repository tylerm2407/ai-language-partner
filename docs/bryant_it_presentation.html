Data Governance

PII Data Flow

Student PII (email, name) is stored only in Supabase PostgreSQL. AI providers receive chat text or voice audio for processing — no student identifiers are sent to ElevenLabs. All AI API providers are contractually prohibited from training on input data.

Access Control

Authentication & Authorization

Authentication

  • Email/password or magic link via Supabase Auth
  • JWT tokens with 1-hour expiry
  • Automatic refresh token rotation
  • MFA (TOTP) supported for admin/teacher roles
  • Email domain restriction for institutional pilots

Role-Based Access Control

RoleAccess Scope
LearnerOwn profile, progress, chat, enrolled classrooms
Teacher+ Classroom management, assignments, grading, student progress
School Admin+ Org management, teacher provisioning, audit logs, data export/deletion

Row-Level Security is enabled on every database table. Students cannot access other students' data. Teachers only see their own classrooms. Admins are scoped to their organization.

Regulatory Compliance

FERPA Alignment

School Official Exception

Fluenci operates as a "school official" under FERPA (34 CFR § 99.31(a)(1)(i)(B)):

  • Performs a service the institution would otherwise use employees to provide
  • Under the direct control of the institution regarding education records
  • Uses records only for authorized educational purposes

Student Data Commitments

  • Data used exclusively for language instruction
  • Never used for advertising or marketing
  • Never sold or shared with third parties
  • AI providers cannot train on student data
  • Institution can export all data at any time
  • Full deletion within 30 days of termination

Audit Logging & Incident Response

Audit Logging

All administrative and security-relevant actions logged to an immutable audit table:

  • Actor ID + role
  • Timestamp + IP address
  • Action type (create, read, update, delete)
  • Resource type and ID
  • Org admins can query their own logs

Infrastructure

Hosting & Resilience

Infrastructure

  • Supabase (managed PostgreSQL) on AWS us-east-1
  • Cloudflare CDN + WAF on all endpoints
  • Edge Functions in Deno isolate sandboxes
  • Database behind connection pooling (no public endpoint)
  • Separate dev/staging/production environments

Backup & Recovery

  • Automated daily backups
  • 30-day point-in-time recovery window
  • RTO: < 4 hours
  • RPO: < 1 minute (database via PITR)
  • 99.9% uptime target (Supabase SLA)

Secrets Management

  • All API keys in Supabase Secrets Manager
  • No secrets in client-side code
  • Service role key server-side only
  • Client uses anon key (limited by RLS)

Vulnerability Management

  • npm audit on every build
  • GitHub Dependabot alerts
  • Critical patches within 48 hours
  • All changes code-reviewed before deploy

Accessibility

WCAG 2.1 AA Conformance

What's Implemented

  • 14.6:1 contrast ratio (exceeds AAA 7:1 requirement)
  • 44pt minimum touch targets (Apple HIG)
  • VoiceOver support with logical reading order
  • All interactive elements have accessibility labels
  • Dynamic Type support (system font scaling)
  • No color-only information conveyance
  • Gesture alternatives for all swipe actions
  • Timer-based exercises can be paused/extended

Anticipated Questions

Questions We're Ready For

Where is data hosted?
AWS us-east-1 (Virginia) via Supabase. US-only. No offshore data transfer.
Do you support SSO?
Email domain restriction (@bryant.edu) for pilot. SAML 2.0 on our roadmap for production rollout.
What happens if you go out of business?
90-day notice with full data export opportunity. All data deleted after export. Documented in BCP.
Who do we call when something breaks?
Dedicated support channel (Slack or email). P1: 1-hour response. P2: 4-hour. Weekly check-ins during pilot.
Can students use this on any device?
iOS and Android apps. No web version currently — mobile-first design.
How is content moderated?
Content safety pipeline validates all AI outputs before display. Stricter filtering for minors. No unreviewed AI content reaches students.
