## Review protocol

1. Read each actual question in its language, course, unit and lesson context.
   Solve from the prompt before reading the key, where feasible. Do not invent
   a unique expected answer for an open-ended prompt.
2. Check the stored answer, alternatives, distractors, linguistic naturalness,
   explanation, lesson-topic alignment and expected proficiency.
3. Record exact item references/IDs and evidence for confirmed defects. Separate
   ambiguity, subjective improvements and unresolved language judgments.
4. Do not rewrite valid questions, silently simplify advanced objectives, or
   rename lessons to conceal mismatched content.
5. A second reviewer assesses content before seeing the first findings.
6. Remediation needs exact before/after evidence, regression tests and a review
   of unintended changes. No deployment is authorized by this audit.

`scripts/question-audit/packet.mjs` produces compact per-unit blind/key packets.
Each packet includes a hash and stable per-language item references. A packet
read is not itself evidence of approval: review results must state what was
actually assessed and what remains pending. Never claim a second pass occurred
if only one was performed.

Future AI-generated content cannot be exhaustively certified in advance.
Generator/validator review is recorded separately from review of existing rows.
Text review of listening transcripts does not verify generated audio quality.
